
# Hotel Booking & Cancellation Analytics

A Power BI project to analyze hotel booking trends and cancellation patterns using real-world hotel booking data.

## Objective of the Project

The objective of this project is to understand booking performance, identify cancellation patterns, and find areas where hotels can improve their booking management.

## Dataset

- **Dataset:** Hotel Booking Demand
- **Source:** [Kaggle](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)
- **Hotels:** City Hotel and Resort Hotel
- **Records:** 119,204 after data cleaning

## Tools Used

- Power BI
- Power Query
- DAX

## Project Work

- Cleaned and transformed the dataset.
- Handled missing values and unusual records.
- Created Total Guests, Total Nights, and Arrival Date columns.
- Created a Calendar table for time-based analysis.
- Built DAX measures for booking performance and cancellation analysis.
- Developed a two-page interactive dashboard.

## Key Insights

- Overall cancellation rate was approximately **37.07%**.
- City Hotel contributed **66.4%** of total bookings.
- Online TA had the highest booking volume.
- Groups had the highest cancellation rate at approximately **61.1%**.
- Longer lead-time bookings were associated with higher cancellation rates.

## Recommendations

- Monitor bookings made far in advance.
- Improve confirmation procedures for group bookings.
- Focus on cancellation management for City Hotels.
- Monitor booking patterns across different market segments.
